# P12 — Backend S3/R2 (opcional, cuando haga falta desplegar)

**Tareas OpenSpec:** 6.2. **Depende de:** P05 (puede hacerse en cualquier momento después).

## Objetivo

1. `blob_backend = { s3 = { bucket, region, endpoint } }` construye `object_store::aws::AmazonS3` (feature `aws` de
   `object_store`) con `AmazonS3Builder::from_env()` para las credenciales (`AWS_ACCESS_KEY_ID`,
   `AWS_SECRET_ACCESS_KEY`) y los campos de la configuración; `endpoint` permite R2 y MinIO. Las credenciales nunca en
   `Config` ni en logs.
2. Misma clave de objeto que en disco; misma semántica de temporal + verificación + movimiento (en S3 «mover» es
   copiar y borrar: usa `copy_if_not_exists` si el backend lo soporta, o `put` condicional; documenta lo elegido y su
   comportamiento con R2). Subidas grandes con multipart.
3. La batería de pruebas del `ContentRepository` de P05 se ejecuta contra ambos backends (función genérica de pruebas
   que recibe el repositorio).
4. Pruebas S3 con `testcontainers` (MinIO), marcadas `#[ignore = "necesita Docker"]`, y una línea en el README con cómo
   ejecutarlas (`cargo test -- --ignored`). No las añadas a CI salvo que el usuario lo pida.

## Hecho cuando

Verificación en verde, pruebas ignoradas ejecutadas al menos una vez en local si hay Docker (dilo en el cierre), 6.2
marcada, README y CHANGELOG.
